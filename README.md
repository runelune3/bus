# 광주광역시 버스 노선도 (OpenStreetMap)

엑셀 파일(`노선별경유리스트(시청).xls`)의 120개 버스 노선 및 13,267개 정류소/교차로 좌표 데이터를 기반으로, **OpenStreetMap(OSM)** 지도 위에서 노선명으로 자유롭게 검색하고 정류장 경로를 확인할 수 있는 웹 애플리케이션입니다.

---

## 🌟 주요 기능

1. **OpenStreetMap 기반 지도 & 광주광역시 BIS 공식 실제 도로망 궤적 적용**
   - 단순 정류장 간 직선 연결이나 단순 추정이 아닌, **광주광역시 버스정보시스템(BIS) 공식 인가 도로 궤적(120개 전 노선 약 9만 개 정밀 도로 꼭짓점 Vertex)**을 100% 매칭하여 실제 주행 차로, 전용도로, 회차지 굴곡을 정확하게 표출
   - 첫 화면 로드 시 전체 120개 노선 목록 즉시 표출 및 카테고리별 탐색 지원
   - 상행/하행/전체 방향별 세부 궤적 분리 렌더링 지원
   - 일반 지도, 깔끔한 밝은 지도, 다크 모드 지도 지원
   - 광주광역시 전역 버스 노선 궤적(Polyline) 및 정류소 마커 시각화

2. **실시간 노선명 검색 (초성 검색 지원)**
   - 검색창에 노선명 입력 시 실시간 자동완성 (예: `급행03`, `1187`, `03`, `수완`, `일곡`)
   - 한글 초성 검색 지원 (예: `ㄱㅎ` 입력 시 `급행03`, `급행05`, `급행06` 즉시 검색)
   - 노선 종류별(급행, 간선, 지선, 순환, 맞춤) 고유 색상 및 배지 적용

3. **정류소명 & ARS 번호 검색 모드**
   - '정류소 · ARS' 탭 선택 후 정류소 이름(예: `광천터미널`, `시청`) 또는 4자리 정류소 **ARS 번호(예: `2468`, `2103`, `1001`)** 직접 검색
   - ARS 번호 완전 일치/접두사 우선 정렬 및 검색어 하이라이트 표시
   - 해당 정류소를 경유하는 모든 버스 노선 목록 조회 및 승강장 위치로 지도 포커스(FlyTo)

4. **대중교통 경로검색 (길찾기: 직통 및 1회 환승)**
   - 상단 '길찾기' 탭 선택 후 출발 정류소와 도착 정류소(이름 또는 ARS 번호)를 입력하여 최적 버스 경로 탐색
   - 소요시간 추정 없이 **순수 경유 정류장 수 및 환승 횟수** 중심 직관적 결과 제공
   - **직통(0회 환승)** 및 **1회 환승(동일 정류소 환승 + 300m 이내 인접 정류소 도보 환승)** 탐색 지원
   - **결과 표출 기준**: 최대 10개 경로 표출, **직통 우선** 정렬 후 **경유 정류장 수가 적은 순서**대로 제공 (순수 최소 정류장 순 토글 지원)
   - 지도 위 출발(A, 초록), 환승(T, 주황), 도착(B, 빨강) 핀 마커 및 실제 BIS 도로 궤적/도보 점선 표출
   - 지도 마커 팝업 내 `[출발]`, `[도착]` 버튼으로 지도에서 직접 정류소 지정 가능
   - 출발지 ⇄ 도착지 한 번에 바꾸는 스왑(Swap) 버튼 지원

5. **지하철/메트로 스타일 정류소 타임라인**
   - 기점 ➔ 회차지 ➔ 종점 순서대로 수직 노선도 표시
   - 상행/하행/전체 방향별 필터링
   - 정류소 클릭 시 해당 위치로 부드럽게 이동(FlyTo) 및 상세 팝업 오픈 (ARS 번호, 정류장 ID)

6. **노선 주행 시뮬레이션**
   - 하단 '주행 시뮬레이션' 버튼 클릭 시 버스 아이콘이 기점부터 종점까지 노선을 따라 실제 주행 애니메이션 시현

7. **GeoJSON 내보내기**
   - 지도 설정 메뉴에서 현재 조회 중인 버스 노선 및 정류장을 GIS 표준 GeoJSON 파일로 다운로드 가능

## 🚀 실행 방법

### 방법 1. `run.bat` 더블 클릭 (가장 간편한 방법)
폴더 내의 `run.bat`을 더블 클릭하면 자동으로 로컬 웹 서버가 구동되고 브라우저에서 `http://localhost:8080`이 열립니다.

### 방법 2. 파이썬 명령어로 직접 실행
```bash
python -m http.server 8080
```
브라우저에서 [http://localhost:8080](http://localhost:8080) 접속

### 방법 3. 최신 엑셀 데이터 재변환 시
엑셀 파일 내용이 갱신된 경우 다음 명령어로 JSON/JS 데이터를 다시 생성할 수 있습니다:
```bash
python build_data.py
```

## 📁 파일 구조

- `노선별경유리스트(시청).xls`: 광주광역시 시청 버스 노선/정류소 원본 엑셀 데이터
- `build_data.py`: 엑셀 데이터를 웹에서 빠르게 사용할 수 있도록 가공하는 파이썬 스크립트
- `routes_data.json` / `routes_data.js`: 119개 노선 궤적 및 정류소 인덱스 데이터
- `index.html`: OpenStreetMap 및 검색 UI 메인 웹 페이지
- `style.css`: 모던 글래스모피즘 & 메트로 스타일 타임라인 디자인
- `app.js`: Leaflet 지도 제어, 검색 알고리즘, 애니메이션 및 인터랙션 로직
- `run.bat`: 윈도우 원클릭 실행 스크립트
